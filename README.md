# HT Auraldo — Sound packs / Gói tiếng

Các gói tiếng và bộ tách stem cho phần mềm HT Auraldo. Cài từ trong phần mềm: **Xem → Thư viện tiếng**.

Sound packs and the stem-separation model for HT Auraldo. Install them inside the app: **View → Sound Library**.

Each file is downloaded and checked (SHA-256) by the app. The packs are made from freely licensed sample libraries; credits and licences below (each pack also carries its licence text).
